## 2. Что проверялось

| Область | Что проверено |
|---------|---------------|
| **UI** | Открытие главной страницы, навигация по меню, отображение списков (автомобили, клиенты, работы, запчасти, исполнители), карточки объектов |
| **API** | Регистрация, логин, получение текущего пользователя, CRUD автомобилей, клиентов, работ, запчастей, заказов |
| **БД** | Создание таблиц, валидация foreign key, обработка NULL значений |
| **Логи** | Отсутствие критических ошибок (500) при основных операциях |
| **Производительность** | Lighthouse, Performance, время загрузки страницы |
| **Перезапуск** | Поведение после `docker restart` |
| **Основной сценарий** | Регистрация клиента → добавление автомобиля → создание заказа → добавление работы → смена статуса |

## 7. Вывод

### Готовность к эксплуатации:

Проект **готов к дальнейшей эксплуатации** с некритичными замечаниями.

### Что работает:
- Полный цикл: клиент → автомобиль → заказ → работы → статус
- Администрирование через веб-интерфейс
- Все API-эндпоинты доступны и корректно работают
- Логи без критических ошибок

### Что нужно улучшить:
1. Настроить автоматическое резервное копирование БД
2. Внедрить HTTPS при реальном развёртывании
3. Добавить пагинацию для больших списков
4. Настроить централизованный сбор логов (ELK/Loki)



**Общая оценка:** Проект может быть передан в эксплуатацию после устранения рекомендаций по безопасности.
