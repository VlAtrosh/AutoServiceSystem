# RELEASE_NOTES.md

## Релиз 0.2.0

### Что исправлено
Исправлена критическая ошибка, из-за которой при создании заказа не добавлялись выбранные работы и механик. Заказы создавались пустыми (total: 0).

### Как проверить
1. Запустить проект: `docker compose -f docker-compose.prod.yml up -d`
2. Открыть http://localhost:8000
3. Войти как admin / admin123
4. Нажать "+ Новый заказ"
5. Выбрать клиента, автомобиль, работы, механика
6. Нажать "Создать заказ"

### Ожидаемый результат
Заказ создаётся с выбранными работами и механиком, сумма корректно рассчитывается.

Нет
