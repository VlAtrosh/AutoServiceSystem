| BUG-06 | UI / Навигация | При клике на пункты подменю "Работы" и "Запчасти" не загружались данные из API | Открыть Справочники → Работы | Низкая | fixed | Исправлена функция setupNavigation, добавлены вызовы loadWorksReference() и loadPartsReference() |
| BUG-07 | БД | Отсутствует автоматическая генерация ID для таблицы clients | Создать клиента без указания ID | Средняя | fixed | В модели Client добавлено default=lambda: str(uuid.uuid4()) |
